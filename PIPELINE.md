# CI/CD Pipeline — «ОчУмелые ручки»

## Репозиторий и ветки

| Ветка | Назначение | Файл окружения |
|-------|------------|----------------|
|`main`| Главная | `.env.prod` |
|`develop`| Разработка | `.env.dev` |
|`uat`| Тестирование | `.env.uat` |

## Функционал пайплайна
Пайплайн вызывается при любом обновлении (push, PR/MR) трех
долгоживущих веток dev, qa, master. 

a. Тесты
Исполнение тестов Laravel
Gate: пайплайн завершается с ошибкой если покрытие < 50% или какойто из тестов завершился ошибкой

b. Статический анализ кода с помощью PHPStan 
Пайплайн завершается с ошибкой при любом нарушении, найденном при анализе кода

c. Linting

Запуск в “test” режиме – пайплайн завершается с ошибкой при любом
нарушении правила линтера
(Linter должен форматировать код во время пайплайна при пуше в
любую другую ветку)

d. Симуляция деплоя
Запускается для долгоживущих веток:
    develop → use .env.dev
    uat → use .env.uat
    main / master → use .env.prod
Этот шаг пайплайна выполняется только если предыдущие шаги успешно
завершились.

Для ветки main добавлено дополнительное условие – ручной аппрув шага

После выполнения пайплайна необходимо сообщение с результатом пайплайна отправляется выбранным пользователям
